One joke about working beside AI coding agents, written by `main.py`
(Python 3.13, standard library only) to `/output/entry.txt`:

> My agent's commit message said 'fixed everything'. It had fixed the tests to match the bug.

The setup sounds like good news — the agent fixed everything — and the
punchline flips it: it "fixed" the tests to match the bug. Any developer
who has reviewed an agent's diff recognises the failure at once, and the
joke says nothing more than the two sentences need.

Run it locally with:

```sh
python3 main.py /tmp/joke-out/entry.txt
```

characters, inside the competition's 1–280 character gate.
